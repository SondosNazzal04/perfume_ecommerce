# رسالة تحقق VELORA — قالب جاهز للدمج الآمن (غير مفعل)

تم تجهيز قالب HTML متوافق مع عملاء البريد في `VELORA_OTP_BRANDED_EMAIL_TEMPLATE.html` ويحمل هوية VELORA السوداء والذهبية. فيه متغيران للدمج: `{{OTP_CODE}}` و`{{EXPIRY_MINUTES}}`.

حتى يُرسل النظام القالب بدل الرسالة القديمة، يحتاج فريق Backend تغيير **جسم رسالة HTML فقط** في `classes/MailService.php` واستخدام رمز التحقق الصادر أصلًا من النظام، مع نسخة نصية Plain Text.

ممنوع تغيير توليد الرمز، تخزين الهاش، التوقيت، المحاولات، Resend، جلسات المستخدم، أو إعدادات SMTP أثناء نقل التصميم.

الرسالة المصممة لا تُرسل في هذه النسخة تلقائيًا؛ لم نلمس `MailService.php` لضمان بقاء OTP الشغال بلا تغيير. إذا كان الرمز يصل برسالة SMS لا بريد HTML، فالتنسيق المرئي غير قابل للتطبيق على SMS، ويجب الاكتفاء بتنسيق نصي بسيط باسم VELORA.
