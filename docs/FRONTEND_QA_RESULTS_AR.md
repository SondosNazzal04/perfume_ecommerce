## لم يتم إثباته بعد
- اختبار تطبيق حي داخل Chromium: المتصفح يشغّل لكن يمنع التنقل إلى عنوان localhost/ملفات الجهاز عبر `ERR_BLOCKED_BY_ADMINISTRATOR`. المعاينات الثابتة ليست اختبار أداء/وظائف حي.
- MySQL/PDO: بيئة PHP الحالية لا تحتوي `pdo_mysql`. استجابة API الحقيقية لم تُختبر؛ لا يوجد نجاح مزعوم للمنتجات/الطلب/الـCheckout.
- Google OAuth: لم يُجرّب مع حساب Google أو redirect URI حي.
- إرسال OTP: لم نغيّر الكود؛ يجب التحقق من عدم وجود Regression على جهاز Windows.
- الدفع: لا يوجد اختبار Stripe أو COD فعلي في هذه البيئة.
- تشغيل مشاهد السائل الذهبي وقت السكرول/عكسه يحتاج اختبار عين مباشر على متصفح المستخدم؛ وجود MP4 وPoster لا يكفي لإثبات تشغيل Timeline.
- Admin endpoints: تحتاج Admin session وMySQL؛ تم تحسين CSS فقط.
