# VELORA — سجل تعديلات نسخة Admin Studio

## ما تغير بالفعل
- بناء طبقة تصميم إدارية إضافية `assets/css/velora-admin-studio.css` لخلفيات الأسود/الذهبي والتباين والخطوط والأزرار والجداول والهواتف، دون تعديل CSS مشاهد الصفحة الأولى.
- استبدال رموز Sidebar النصية بأيقونات SVG موحدة وإضافة روابط `Inventory` و`Coupons` مع تمييز الصفحة الحالية و`aria-current`.
- استبدال رمز الشطرنج ♙ في `index.php` بأيقونة حساب SVG واحدة، دون تغيير بقية لاندينغ V2 أو أي حركة.
- `admin/inventory.php` + `assets/js/admin-studio.js`: استعراض المخزون الإجمالي من `api/admin/catalog.php`، فتح الأحجام وبياناتها من `api/product-variant.php` وتعديل كمية حجم محدد عبر PUT الحالي بتأكيد صريح. لا تُغيّر الأسعار أو بقية خصائص المتغير.
- في `admin/products.php`: اختيار منتجات **الصفحة الحالية فقط** وتنفيذ Publish أو Unpublish تباعًا عبر GET/PUT الموجودة، مع المحافظة على اسم المنتج وتصنيفه ووصفه وكافة الفئات. عند فشل خطوة تتوقف العملية فورًا ويُعرض عدد ما تم تغييره؛ ليست معاملة واحدة قابلة للتراجع تلقائيًا.
- `admin/coupons.php`: إنشاء كوبون عبر `POST api/coupons.php` الموجود، مع التحقق من الحقول والتأكيد. لا يوجد عرض أو تعديل/حذف لكوبونات مجهولة؛ لأن نفس API لا تقدم GET.
- تحسين دعم غياب `mbstring` في عرض حرف اسم الأدمن فقط؛ دون تغيير تسجيل الدخول أو الصلاحيات.
- تحسين `aria-expanded` عند إغلاق Sidebar بالنقر خارجها.
- إضافة قالب رسالة OTP **مرجعي فقط** في `docs/VELORA_OTP_BRANDED_EMAIL_TEMPLATE.html`. لم يُركّب تلقائيًا داخل خدمة البريد لحماية كود التحقق والشحن البريدي الحالي.

## ما لم يتغير
- قاعدة البيانات وجداولها وملف SQL: صفر تعديلات.
- مجلدات منطق الفريق: `actions/`, `api/`, `classes/`, `config/`, `core/`, `database/`: صفر تعديلات.
- عملية OTP الفعلية، Google OAuth، Stripe، حساب الأسعار والطلبات: صفر تعديلات.
- الفيديوهات والمشاهد السينمائية والـGSAP والصور: صفر تعديلات.
- **لم تُضف Sales Analytics جديدة** وفق طلب مالك المشروع. الرسم الحالي الموجود مسبقًا في Dashboard بقي كما كان.

## ما يحتاج دعم الفريق قبل ادعاء اكتماله
- Google Login: يتطلب مطابقة Google Cloud Redirect URI مع الرابط المحلي الحقيقي للموقع، راجع `GOOGLE_LOGIN_CALLBACK_FIX_AR.md`.
- قالب البريد: يحتاج دمجًا محدودًا داخل `classes/MailService.php` بواسطة مسؤول الباك إند بعد الاختبار؛ الملف المرسل حاليًا مثال تصميم غير مفعل.
- إدارة الكوبونات الكاملة (عرض/بحث/تعديل): تحتاج endpoint قراءة GET بصلاحيات Admin؛ لا تحتاج أي تغيير Schema.
